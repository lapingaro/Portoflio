05
Godot Editor Plugin · PPE Selection System · Tool Development
PPE Selection Module for Mining Safety Training
A Godot 4 Editor Plugin and runtime system for selecting, equipping and grading Personal Protective Equipment (PPE) in VR mining safety simulations. The system combines an editor dock for defining task-based and hazard-based PPE requirements with an in-game runtime that includes a 6-category selection UI, character preview and a three-state visual feedback system for training assessment.
Game Mechanics & Design Elements
  • Dual-layer architecture — editor tool (JSON data authoring) decoupled from runtime system (.tres resource-based) for type-safe in-game selection
  • Task-based and hazard-based rule engine — PPE requirements combine from both inputs with automatic deduplication
  • 6-category selection system (HAT, EYE, EAR, HANDS, FEET, KNEES) with per-category scrollable rows and character preview slots
  • Equip-lock mechanism — selections locked after first confirmation, preventing changes in training/graded scenarios
  • Three-state result feedback — green border (correct selected), red border (incorrect selected), light green (correct but missed)
  • Singleton state manager (PPEManager) with persistent save/load to JSON, supporting session continuity
  • Planned TaskManager integration via PPETaskValidator bridge — single-task pass/fail grading for all PPE categories

04 · Methodology

My serious game
design process.

01
Needs Analysis
Understand the learning objective, target audience, context and constraints through stakeholder interviews and systems mapping.
02
Mechanics Design
Define core game loop, feedback systems, branching logic, win/lose conditions and how mechanics mirror real-world decisions.
03
Prototype & Test
Build a rapid prototype — physical or digital — and test with a small group to validate that mechanics produce intended learning behaviours.
04
Develop & Refine
Full development in Godot or Unity, integrating narrative, 3D assets, VR hardware and performance optimisation. Iterative refinement with stakeholders.
05
Facilitate & Debrief
Run the session, manage group dynamics and lead structured debriefing — bridging game experiences to real-world insights and actionable outcomes.
Consequence-Driven Design
Every decision in a serious game should have a meaningful consequence that reflects real-world outcomes. Players learn through cause-and-effect, not instruction.
The Debrief is the Game
The play session generates the experience; the debrief generates the insight. I design both the game mechanics and the facilitation framework as inseparable parts of the learning experience.
Context Before Content
Games that work in one cultural context may fail in another. I design for specific audiences, adapting language, metaphor, complexity and mechanic style to the learners — not a generic template.
